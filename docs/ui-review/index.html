Shiftly · واجهة يوم الشغل

الواجهة مبنية حول المعلومات والإجراءات: وقت الشيفت المتبقي والمنقضي، البريك، الانصراف والتسليم، إنجاز المهام، واختيار مساحة العمل قبل الدخول.

لقطات Flutter ببيانات تجريبية معزولة. الرئيسية والمهام واختيار المساحة من شاشات التطبيق. معاينة المحادثة تستخدم مكوّنات الإنتاج داخل صفحة مراجعة دون تشغيل صوت فعلي. التعديلات محلية ولم تُنشر.

اللوجو وشاشة البداية والتحميل

شاشة البداية تعرض اللوجو وجملة «فريقك وشيفتاتك… في مكان واحد» فقط. فحوص الحالة والتحديث تستمر في الخلفية. يستخدم تحميل البيانات حزمة Shimmer مع احترام تقليل الحركة، وتظل مؤشرات الحفظ والإرسال داخل الأزرار.

إعادة تجهيز الأصول: dart run scripts/prepare_brand_assets.dartdart run flutter_launcher_iconsإعادة التقاط الصور: flutter test --no-pub --dart-define=UI_BRAND_CAPTURE=true test/brand_refresh_test.dart

سلوك البريك والوقت

البريك مؤقت محلي لمدة ساعة على الجهاز، محفوظ عند إغلاق التطبيق. لا يخصم من الحضور ولا يرسل تغييرًا للسيرفر، ولا تتزامن حالته بين الأجهزة. يتوقف التنبيه عند إنهاء البريك أو الانصراف المؤكد أو الخروج من الحساب.

تنبيه الخلفية يستخدم الإشعارات المحلية على Android وiOS ويتطلب الإذن. إذا لم تتوفر الجدولة الدقيقة على Android فقد يؤخر النظام التنبيه؛ الويب يعرض المؤقت داخل التطبيق. يلزم اختبار التنبيه على جهاز فعلي قبل النشر.

الوقت المعروض يتحدث محليًا من آخر حضور مؤكد. مدة العمل النهائية يؤكدها السيرفر. تسليم الشيفت يفتح مسار التسليم الحالي، ولا يسجل انصرافًا تلقائيًا.

المهام

شريط الإنجاز يحسب إجمالي المهام المفتوحة والمكتملة عبر كل الصفحات، ويتحدث بعد الإكمال أو إعادة الفتح. يعرض حالة غير متاحة إذا تعذر تحميل الإجماليات؛ لا يخترع نسبًا لبنود فرعية غير موجودة في البيانات.

إعادة التقاط الصور

flutter test --no-pub --dart-define=UI_CAPTURE=true --dart-define=UI_STAGE=layout test/capture_ui_review_test.dart
